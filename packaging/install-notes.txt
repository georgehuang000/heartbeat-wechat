心动微信 0.1.0 · 安装前说明

适用环境：Windows 10 2004（19041）及以上 / Windows 11，x64 电脑。
需要 .NET Framework 4.8 与 Microsoft Edge WebView2 Runtime。
当前安装包不含 WebView2 Runtime。如缺少，请通过安装窗口的 Microsoft 官方入口下载安装后重试。

程序默认仅安装到当前用户目录，不需要管理员权限。
升级前请先完全退出已经运行的心动微信，再覆盖安装。

首次使用需运行兼容版本的 Windows 微信，并自行配置聊天 API 的地址、协议、模型及密钥。
生成建议会将相关聊天上下文以及启用的附件发送给你配置的模型服务商，可能产生调用费用。
本程序只在你选择后填入微信草稿，消息仍由你手动发送。

卸载只删除程序文件，保留 %LOCALAPPDATA%\HeartWeChat 内的设置与本地记录。
请在确认不再需要时自行删除该数据目录。

这是独立项目，与微信官方无关联。签名状态以下载页和安装文件属性中的数字签名为准；未签名的预览版可能显示未知发布者。

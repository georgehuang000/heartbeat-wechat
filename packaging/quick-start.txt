心动微信 0.1.1 · 使用说明

1. 安装与启动
运行下载的 HeartWeChat-Setup 安装包，按提示完成安装。
默认路径：%LOCALAPPDATA%\Programs\HeartWeChat
从桌面或开始菜单打开「心动微信」。安装后的首次启动可能需要等待单文件资源展开。

2. 连接模型
在 设置 → 连接 中填写 API 地址、协议、模型与密钥，并保存。
协议支持 OpenAI Chat、OpenAI Responses、Anthropic Messages；实际兼容性取决于服务商。
模型调用可能收费，相关上下文与已开启的附件会发送至你配置的服务商。

3. 使用聊天辅助
保持 Windows 微信与心动微信同时展开、未被其他软件遮挡，切换到要回复的聊天。
默认不需要逐联系人授权；可在设置里开启「按联系人询问辅助」，再逐人决定。
询问模式下，未开启也可在本地识别聊天；点击中央「开启此聊天」后，才允许把必要内容提交给配置的模型。
自动生成默认等待最后一条新消息后安静 3 秒；这个等待可以关闭。
历史读取可填写 10–5000 的任意整数，请根据成本和实际需要选择。
切到其他软件、任一窗口被遮挡或收起时暂停。主动收起心动微信后，点击微信不会把它弹回；从任务栏或启动入口恢复。
聊天内容没有变化时保留已有选项并待命，不重复生成。生成中断后，相同内容需明确重试。

4. 选择、修改，再发送
选择一条建议填入草稿。你可以在微信中修改，最后自行发送。
关系记录由你确认，不会因为点击建议而自动推进关系。
网页演示中的联系人与对话均为虚构，不连接真实微信。

5. 数据与升级
设置及本地记录：%LOCALAPPDATA%\HeartWeChat
升级前完全退出心动微信，重新运行安装包覆盖安装。
卸载保留数据目录；安装包不包含开发者的 API 密钥或聊天记录。

6. 环境要求与排查
Windows 10 2004（19041）及以上 / Windows 11，x64；.NET Framework 4.8；WebView2 Runtime。
标准包携带 Microsoft 官方 WebView2 安装引导程序。已有组件时跳过；缺少时由安装器从 Microsoft 下载并安装，请保持联网，无需提前手动安装。
如果组件下载失败，可检查网络后重试，或从下方下载页选择完整离线包；离线包已携带运行库，无需联网下载组件。
安装包下载页：https://github.com/georgehuang000/heartbeat-wechat/releases/tag/v0.1.1
组件安装成功后仍需联网连接你配置的聊天 API。WebView2 由 Microsoft 后续更新，卸载心动微信时保留。
若组件安装失败，请保留安装日志中的错误码并重试；如提示需要重启，请保存工作并重启后重新运行安装包。
官方下载：https://developer.microsoft.com/microsoft-edge/webview2
微信版本、窗口结构或模型接口变化可能影响兼容性；其他电脑仍需实际验收。
请核对下载页上的签名状态、文件属性中的数字签名及随包 SHA-256 校验文件。未签名的预览版可能显示未知发布者；新签名版本也可能出现 SmartScreen 信誉提示。

本程序为独立项目，与微信官方无关联。
